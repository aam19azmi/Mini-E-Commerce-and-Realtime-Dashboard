\section{Executive Summary}
NovaStore is a modern, high-performance digital commerce application built for single-merchant operations. It eliminates checkout friction by providing an instantaneous multi-product guest checkout while equipping store administrators with a real-time command center powered by Supabase PostgreSQL WebSockets.

\section{Core Capabilities}
\begin{itemize}
    \item \textbf{Frictionless Guest Checkout:} Instant multi-item purchasing without account creation or login hurdles.
    \item \textbf{Interactive Geolocation \& Courier Engine:} Integrated map coordinate pinning with dynamic distance calculation (Haversine formula) for JNE, J\&T, SPX, SiCepat, and Instant Couriers.
    \item \textbf{2.5\% Platform Service Fee:} Automated fee calculation itemized across checkout, receipts, tax invoices, and reporting.
    \item \textbf{Direct Zero-Fee Payment Verification:} Support for instant QRIS, Bank Transfer proof receipt upload with 1-click admin approval/rejection, and Cash on Delivery.
    \item \textbf{Live Administrative Dashboard:} Real-time WebSocket subscriptions, visual analytics charts, full product catalog CRUD, and 1-click CSV export.
    \item \textbf{Official Commercial Tax Invoices:} Corporate invoicing formatted to Indonesian standard with verified cryptographic QR validation.
\end{itemize}

\section{Mathematical \& Fee Formulations}
The application calculates order totals according to the following formulas:
\begin{equation}
\text{Product Subtotal} = \sum_{i=1}^{n} (\text{Price}_i \times \text{Quantity}_i)
\end{equation}

\begin{equation}
\text{Admin Fee} = \text{Round}(\text{Product Subtotal} \times 0.025)
\end{equation}

\begin{equation}
\text{Shipping Tariff} = \text{Base Cost} + (\text{Distance (km)} \times \text{Tariff/km})
\end{equation}

\begin{equation}
\text{Grand Total} = \text{Product Subtotal} + \text{Shipping Tariff} + \text{Admin Fee}
\end{equation}
